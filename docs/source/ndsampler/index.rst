=========
NDSampler
=========

The purpose of NDSampler is to encapsulate calls to the `NJOY <https://github.com/njoy/NJOY2016>`_ nuclear data processing code and to the `Sandy <https://github.com/luca-fiorito-11/sandy>`_ nuclear data sampling library to generate perturbed nuclear data usable for OpenMC calculations.
